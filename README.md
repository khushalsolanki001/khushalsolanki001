## About Me

I'm **Khushal Solanki**, an MCA student and software developer from Gujarat, India.

I enjoy turning ideas into usable products across **mobile, web, AI, cloud, and games**. I work mainly with Flutter/Dart, modern web technologies, backend services, and game-development tools.

Currently focused on:
- Building **OpenKhata**, an offline-first GST billing and accounting product for small businesses.
- Exploring **AI application development**, APIs, deployment, and modern ML workflows.
- Creating experimental web experiences and games as an indie developer.
- Growing **Volphy Studio**, my solo software and game studio.
